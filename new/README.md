# 🌱 보카하이 (vocahigh)

> **교육용 단어 암기 시스템 & 7단계 보카 트리**  
> Supabase 정식 인증(Auth) 및 클라우드 데이터베이스 1:1 연동 웹 애플리케이션

---

## 🌟 주요 기능

1. **정식 회원가입 & 로그인 (Supabase Auth)**
   - 구글 이메일(`user@gmail.com`) 및 비밀번호(6자 이상) 기반 정식 계정 생성.
   - 로그인된 사용자별 고유 UUID를 기준으로 학습 데이터 1:1 완벽 격리.

2. **보카 트리 (Voca Tree)**
   - 학습이든 복습이든 단어 1개당 무조건 **☀️ 햇살 1개** 획득.
   - Lv.1 씨앗(🌱)부터 Lv.7 불멸의 세계수(👑)까지 7단계 성장 시스템.

3. **에빙하우스 망각곡선 3대 주기 복습**
   - 1일, 7일, 30일 주기에 맞춘 장기기억 고정 복습 훈련.

4. **워드 리콜 (Word Recall)**
   - 4지선다형 회상 인출 훈련을 통해 단어 기억을 완벽히 인출.

5. **출석 체크 도장판**
   - 커리큘럼 생성 시 설정한 4종 인정 기준(학습 단어장, 플래시카드, 워드 리콜, 스펠링 훈련) 완료 시 당일 출석 도장 날인.

---

## 🚀 실행 방법

별도의 복잡한 설치 없이 브라우저에서 바로 실행할 수 있습니다:

1. `index.html` 파일을 더블 클릭하여 크롬(Chrome) 또는 엣지(Edge)로 엽니다.
2. **[회원가입]** 탭에서 구글 이메일과 비밀번호를 입력하고 가입합니다.
3. **[로그인]** 탭에서 로그인 후 나만의 보카 트리를 키워보세요!

---

## ⚙️ 설정 파일 (`config.js`)

GitHub 배포 시 `config.js` 파일에서 Supabase 프로젝트 접속 정보를 손쉽게 관리할 수 있습니다:

```javascript
window.VOCAHIGH_CONFIG = {
  SUPABASE_URL: "https://<your-project-ref>.supabase.co",
  SUPABASE_ANON_KEY: "<your-anon-key>"
};
```
